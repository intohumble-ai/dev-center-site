Claude 한도 자동 재개 데몬 Claude Auto-Resume Daemon

Claude Code 사용 한도에 걸려 멈춘 세션을 한도 해제 후 자동으로 이어가는 데몬

사용 한도에 걸리면 세션이 멈추는 문제를 풀려고 2026-06-02 Claude 최적화 작업 때 도입한 도구다. 외부 오픈소스 claude-auto-resume 스크립트(약 730줄 bash)를 설치하고, 한도 감시 데몬(node)을 systemd 사용자 서비스로 상시 가동한다. 데몬이 한도 해제 시각을 읽고 tmux 세션에 계속하라는 입력을 넣으며, 재개 성공 후 오래된 배너가 남지 않게 화면 기록을 비운다. 직접 만든 코드라기보다 설치·설정한 도구라는 점을 밝혀 둔다.
