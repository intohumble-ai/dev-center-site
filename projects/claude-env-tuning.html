Claude 작업환경 최적화 Claude Workflow Tuning

Claude Code를 더 효율적으로 쓰기 위한 설정·훅·스킬·메모리 체계 구축

매매봇이 아니라 도구로서 Claude 자체의 효율을 높이는 작업 묶음이다. 2026-06에 WSL의 Claude 설정을 단일 원본으로 두고 윈도우 쪽 Claude Code가 심볼릭 링크와 wsl.exe MCP 래퍼로 공유하게 융합했다. 안 쓰는 스킬 27개를 비활성화하고 스킬 목록 예산을 늘렸으며, 상태줄(모델·폴더·브랜치·컨텍스트·비용), 파이썬 문법 검사 훅, 최신 라이브러리 문서를 주입하는 context7 MCP, 비용 추적 도구를 추가했다. 이후 7월에는 쌍둥이 봇 드리프트 점검, 미결 장부 스위프, 전수감사 절차 스킬 3종과 DB 읽기 전용 스냅샷 도구를 만들었다. 설정은 홈의 .claude 폴더에 있어 별도 저장소가 없고 줄수는 세지 않았다. 윈도우 Desktop 쪽 연동은 보류 상태다.
