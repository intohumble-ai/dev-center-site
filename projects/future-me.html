내일의 나 (성장 다이어리·미래 운영실) future-me

PC·모바일 같은 계정으로 쌓는 개인 성장 다이어리 — 빠른 메모 자동 분류·루틴·습관·일정 알림·카카오 메모 연결(Next.js + Cloudflare Workers + D1), v1.1→v1.15

생각이 떠오를 때 바로 적고, 그것이 루틴·습관·일정·아이디어로 자동 분류돼 쌓이는 개인 운영실을 목표로 만들었다. Codex 프로젝트 중 가장 활발히 갱신 중(커밋 27개, 5일간). 빠른 메모(규칙 + 모델 분류), 루틴·성장 기록, 카카오 메모 연결, 따라쓰기 타이핑, 일정·알림, 습관 형성, 아이디어 보관함, 오늘의 초점, 작은 시작, 기록 검색·복습, 반려 동반자, 휴대폰 연결(QR)을 담았다. PC 의 ChatGPT 구독을 쓰는 pc-bridge(Windows 자동시작 PowerShell 포함)와 kakao-relay 를 별도 도구로 두었다. 테스트는 node --test 기반 30파일(약 200건)이며 QA 묶음을 버전마다 문서로 남긴다. PC 가 꺼진 상태의 실모델 응답, 자동시작 적용은 아직 검증 전이다.

실적·잔고·수익률은 공개 정책상 표시하지 않습니다(설정으로 켤 수 있음). 상태는 PC 의 빌더가 10분마다 읽어 올립니다.

  1. 시간대별 인사말이 서버·클라이언트에서 달라 hydration 불일치가 났고 렌더 시점을 맞춰 고쳤다
  2. 웹 다운로드 자산의 25MiB 제한을 배포 중 발견해 묶음을 나눴다
  3. 아이디어 화면이 중복 렌더링되던 문제를 수정했다
  4. 늦게 도착한 모델 분류 결과는 원문·권한·수정 상태가 그대로일 때만 적용해 경쟁 상태를 막았다
  5. 권한 철회 뒤 요청은 409 로 거절되는지, SQLite 동시 100요청에서 중복이 없는지 테스트로 확인했다
