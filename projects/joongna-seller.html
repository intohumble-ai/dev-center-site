중고나라 자동 판매 Joongna Seller

중고나라 판매글을 자동 등록·끌어올리고 CGV 보유표를 판매글로 동기화하는 도구

Playwright 웹 자동화와 쿠키 세션으로 중고나라에 판매글을 등록하고, 끌어올리기(수정 저장으로 상단 노출)까지 자동으로 하는 도구다. YAML 상품 파일을 주면 이미지·카테고리 선택·가격 책정을 거쳐 등록하며, 기본은 드라이런이고 --post를 줘야 실등록한다. 이후 CGV봇의 보유표 장부를 판매글로 동기화하는 sync(11시/17시 타이머)와 승인·카드이미지 생성 모듈이 추가됐다. 킬스위치 파일이 없으면 실게시가 no-op이 되도록 막아 두었다. git 저장소가 아니므로 날짜와 커밋 수는 파일 수정시각 기준(커밋 수 없음)이다.

  1. Playwright 헤드리스에서는 서버측 토큰 회전이 안 돼 keepalive 타이머가 실효성이 없었다(실증). 실제 Edge에서만 갱신된다

  3. 이미지 최소 1장이 없으면 등록이 불가능하다
  4. keepalive 타이머는 현재 비활성이며 sync 타이머만 활성이다(2026-10-09 확인)
