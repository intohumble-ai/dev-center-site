모든 프로젝트를 한 곳에 누적하는 공개 포트폴리오 + 아이디어 큐를 자동으로 구현·감사·배포하는 엔진

여러 봇을 동시에 만들다 보면 무엇을 어디까지 했는지 잊고 끝맺지 못한 채 다른 일로 넘어가는 일이 잦았다. 그래서 GitHub·LinkedIn 처럼 개발 이력이 전부 쌓이는 자리를 만들었다. PC 의 엔진이 5분마다 각 봇의 상태(서비스 가동·로그 신선도)와 아이디어 큐를 읽어 정적 사이트로 빌드하고 공개 저장소에 올린다. PC 가 꺼져도 마지막 스냅샷이 남는다. 아이디어는 소유자 전용 텔레그램 봇으로만 들어오고, 엔진이 한 번에 하나씩 별도 워크트리에서 구현 → 테스트 → 콜드 감사 → 배포 금지시간 회피 → 배포 → 헬스체크(실패 시 롤백)를 진행한다. 공개 빌드 직전에 비밀 스캐너(정규식 + .env 값 대조)가 돌아 하나라도 걸리면 발행이 중단된다.
