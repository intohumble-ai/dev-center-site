난세출세기 — 삼국지 RPG (웹) Samguk RPG

Vite+TypeScript+PixiJS 브라우저 삼국지 2D 도트 RPG — 이름 없는 병사에서 전직·임관·계급·영지까지. W0~W4 를 워크트리 병렬 개발 + 웨이브별 콜드 감사(FAIL→수리→PASS)로 진행

혼자 플레이하지만 AI 유저가 "다른 플레이어" 역할을 하는 서버 없는 삼국지 RPG. 병사로 시작해 Lv10 전직, Lv15 임관, 공적으로 계급(병졸~태수)을 올리고 영지를 다스리는 출세 루프가 핵심이다. 바람의나라풍 마을 + 이터널시티 UI + 진삼국무쌍 연출을 참고했고 원작 그림·이름 복제는 금지로 명문화했다. 철칙은 sim↔render 분리와 시드 RNG 만 사용 — purity 테스트가 sim/data 파일마다 Pixi·DOM·Math.random 사용을 검사한다. 필드 RPG(몬스터 FSM·전투), 퀘스트 엔진, 아이템 강화·세트, 전장(거점 점령·격문·분대), 세계 시뮬(세력 AI·외교·365일, Web Worker), 계급·영지·세율·민심, 2차 전직 8직업, IndexedDB 저장 v5 마이그레이션을 담았다. vitest 테스트 58파일(약 590~650건). W0 뼈대→W1 RPG 루프→W2 전장→W3 세계→W4 출세·영지를 각각 별도 워크트리에서 만들고 웨이브마다 콜드 감사를 받아 PASS 후 병합했다. W4 "한 바퀴 120분" 관문은 12판 중 7판 도달로 미달 — 결정 대기 상태로 정직하게 기록했고 W5(전면전·다듬기)가 다음이다.
