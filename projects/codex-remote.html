OpenAI Codex CLI를 웹 터미널로 독립 세션 여러 개 띄우는 프록시

Claude 원격 터미널과 같은 방식으로 Codex CLI 세션을 브라우저에서 쓰게 한 구성이다. 윈도우 문서 폴더 아래에 Node 프록시(session-proxy)와 실행 스크립트가 있고, 사용자 서비스로 프록시와 작업 세션별 ttyd 유닛이 돈다. 접속은 내부망(tailnet) 한정이며 각 세션은 데스크톱 앱 대화를 잇는 게 아니라 별도 Codex CLI 세션이다. 코드는 WSL 홈이 아닌 윈도우 쪽에 있어 이번 조사에서 줄수는 세지 않았다.
