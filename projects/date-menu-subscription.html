ChatGPT 구독 연결 테스트 도구 date-menu-subscription

배포 사이트와 별개로, 이 PC 의 ChatGPT 구독으로 모델 응답을 받아볼 수 있는지 확인한 일회성 Node 도구(PKCE 로그인 + Responses SSE)

배포 사이트의 ChatGPT 로그인은 사용자 식별만 한다. 사용자 본인의 구독 권한으로 실제 모델 호출이 가능한지 PC 에서 따로 검증하려고 만든 의존성 없는 Node 스크립트다. PKCE 로그인, 계정별 모델 선택, Responses API SSE 스트리밍(store:false), 세션의 로컬 보호 저장을 구현하고 "저녁 메뉴 후보" 질문으로 1회 검증했다. 다른 사람에게 구독을 제공하거나 사이트 버튼을 자동 활성화하는 도구가 아니다. 검증 목적을 달성해 종료했고, 이 구조는 이후 couple-travel·couple-ledger·future-me 의 pc-bridge 로 이어졌다.

세션 제목과 커밋 제목만 표시합니다. 대화 내용·파일·경로는 공개하지 않습니다.

  • PKCE 기반 ChatGPT 로그인
  • 계정별 사용 가능 모델 선택
  • Responses API SSE 스트리밍 요청(store:false)
  • 등록·세션 정보 로컬 보호 저장
  • 모의 데이터 검증 스크립트(test.mjs) 와 Windows 실행 배치
