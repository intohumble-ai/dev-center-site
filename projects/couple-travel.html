우리의 여행 couple-travel

두 사람이 PC 에서 여행지 비교·지도·일정·예산·항공/숙소 견적을 함께 정리하는 한국어 여행 작업실(Next.js + Cloudflare Workers + D1, Leaflet 지도)

여행 준비가 메신저·메모·엑셀로 흩어지는 문제를 풀려고, 여행방 하나에 둘이 초대로 들어와 같은 데이터를 보며 계획하는 PC 용 웹앱을 만들었다. D1 공동 저장과 5초 동기화·충돌 감지·변경 기록 복원, 여행지 5곳 비교와 일정 초안(지도 연동), 예산·견적·예약/결제/환불 기록, 항공·숙소 검색 링크 실험실, 날씨 예보, 공유 대화와 AI 일정 초안(JSON), 시차 계산, JSON/ICS/PDF 내보내기를 갖췄다. 로컬 PC 의 ChatGPT 구독을 연결하는 pc-bridge 를 별도 Node 도구로 두었다. Codex Desktop 으로 개발. 실제 결제·주문·환불 API 는 연결하지 않았고, 사용자 시나리오 점검 라운드를 돌며 UI 를 다듬는 단계다.

실적·잔고·수익률은 공개 정책상 표시하지 않습니다(설정으로 켤 수 있음). 상태는 PC 의 빌더가 10분마다 읽어 올립니다.

  1. 지도가 편집창·드롭다운을 가리는 문제 → 지도를 기본 접힘으로 두고 레이어를 격리했다(수정 전후 스크린샷을 qa/ 에 남김)
  2. 모달을 닫거나 새로고침할 때 미저장 예산 입력이 사라지는 손실을 막는 처리를 넣었다
  3. 빠른 연속 저장이 중복 기록을 만들어 중복 저장을 차단했다
  4. 계획 복원·AI 일정 적용이 금융 기록(결제·환불)을 과거 상태로 되돌리지 않도록 보호했다
  5. 아직 받지 못한 환불은 순지출에서 차감하지 않는 규칙으로 집계 왜곡을 피했다
