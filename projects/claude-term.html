중지 운영 인프라 Claude Code

원격 터미널 (Claude 웹 터미널) Claude Remote Terminal

ttyd와 tmux로 폰·다른 기기에서 Claude Code 세션에 붙는 원격 접속 묶음

집 PC의 Claude Code를 외부에서 이어 쓰려고 만든 웹 터미널 실행 스크립트 모음이다. ttyd로 터미널을 웹에 내보내고 tmux로 세션을 유지하며, 처음에는 cloudflared 공개 링크로 열었다. 2026-09-10 보안 조치로 공개 인터넷 노출 경로를 끄고 내부망(tailnet) 접속만 남겼다. 같은 폴더의 터널 스크립트는 Meta 심사용으로 법적 페이지만 임시 공개하는 데 쓰였다. 이 폴더의 자체 서비스는 현재 꺼져 있고, 같은 계열의 Codex 원격 세션 프록시와 ttyd 작업 세션 유닛들이 별도로 돌고 있다.
