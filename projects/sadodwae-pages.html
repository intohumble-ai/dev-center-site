사도돼 공개 사이트 Sadodwae Public Site (Cloudflare Worker)

사도돼?의 고객 면: Cloudflare Worker와 D1으로 판정 요청을 받고 결과를 보여주는 공개 사이트

사도돼?는 상품 링크를 넣으면 근거 기반으로 사도돼(초록)·기다려(노랑)·굳이(빨강)를 판정해 주는 서비스이고, 이 저장소는 그 공개 웹 면이다. 고객 경로가 로컬 PC를 절대 거치지 않도록 Cloudflare Worker와 D1 데이터베이스에 요청을 저장한다. 비공개 봇(toss-marketing-center)이 바깥으로 나가는 HTTPS로 대기 요청을 가져가 판정을 계산해 돌려주며, 워커에는 판정 로직이 없고 받은 값을 검증해 그대로 그리기만 한다. 홈 화면은 D1에서 서버 렌더링하고 카테고리별 공개 개수 상한을 둔다. 요청 폼, 결과 페이지, 공유·피드백, SEO 별칭, 법적 페이지를 포함한다. git 저장소는 아니고 파일 백업본이 여러 개 남아 있으며 배포 상태는 이번 조사에서 확인하지 못했다.
