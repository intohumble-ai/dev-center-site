코인봇 V2 설계·사전 감사 (Codex) Codex Coinbot Design

업비트 현물 코인봇 V2 의 설계·읽기전용 사전 감사·SAFE 골격·전략 연구를 Codex Desktop 세션 18개로 진행한 기록(2026-08) — 결론은 "라이브 미승인"

기존 코인봇(adaptive·trend·swing)이 같은 API 키와 텔레그램 토큰을 공유하고 재부팅 자동시작까지 켜져 있어, 새 봇을 그냥 얹으면 사고가 난다는 판단에서 시작했다. 코드를 짜기 전에 설계와 읽기전용 감사를 먼저 했다. 산출물은 설계·구현 계획, 읽기전용 사전 감사(Phase 0), 텔레그램 운용비서 계획, 구현 상태 보고 등 문서 4종과 네트워크·주문 코드가 없는 Python SAFE 골격(unittest 약 70건)이다. 전략 연구에서는 BTC 비하락장 추세 후보가 비용 ▮▮배 조건에서도 양의 성과를 냈지만 외표본 거래 수가 부족해 라이브 승인하지 않았고, ETH 후보는 탈락했다. 이후 구현은 WSL 의 coinbot-v2 저장소로 넘어갔다. 여기엔 설계와 판단 기록만 남는다.
