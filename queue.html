아이디어 큐

소유자가 텔레그램으로 적은 아이디어가 순서대로 쌓이고, PC 의 엔진이 한 번에 하나씩 별도 워크트리에서 구현 → 테스트 → 콜드 감사(다른 모델이 diff 만 보고 반증) → 배포 금지시간 회피 → 배포 → 헬스체크(실패 시 자동 롤백) 를 진행하도록 만들었습니다.

현재 상태(2026-10-10): 엔진은 실가동 1건(게임 상태 요약 함수)을 구현→테스트→감사→배포까지 완주했습니다. 그러나 실돈이 걸린 봇까지 자동 배포하기에는 콜드 감사가 3연속 FAIL — 변조를 사후 흔적으로 탐지하는 방식은 우회 경로가 계속 나왔습니다. 그래서 자동 구현은 일시정지하고 샌드박스 격리 방식으로 재설계 중입니다. 아이디어는 쌓이지만 사람이 풀어줄 때까지 돌지 않습니다.
