아이디어 큐

소유자가 텔레그램으로 적은 아이디어가 순서대로 쌓이고, PC 의 엔진이 한 번에 하나씩 커널 격리 상자(bwrap) 안의 저장소 사본에서 구현 → 커밋만 회수(fetch) → 깨끗한 사본·네트워크 차단 상자에서 테스트 → 콜드 감사(다른 모델이 diff 만 보고 반증) → diff 위생 관문 → 배포 금지시간 회피 → 배포 → 헬스체크(실패 시 자동 롤백) 를 진행하도록 만들었습니다.

현재 상태(2026-10-10): 1세대 엔진(호스트 워크트리 + 사후 지문 탐지)은 콜드 감사 3연속 FAIL 로 폐기했고, 2세대 엔진은 구현·테스트를 샌드박스 상자 안에서만 돌립니다 — 상자에는 실 HOME·다른 저장소·토큰이 존재 자체가 보이지 않고, 쓸 수 있는 곳은 사본 하나뿐입니다. 실돈이 걸린 봇은 새 엔진의 배포 성공 5건까지 소유자 승인 뒤에만 배포합니다.

안전장치

  • 한 번에 하나만. bwrap 상자 안의 폐기용 사본에서 구현 — 실 HOME·다른 저장소·인증 토큰은 상자에 없음(가동 중인 코드는 보이지도 않음).
  • 회수는 커밋(객체)만 fetch. 테스트는 .git 도 네트워크도 없는 깨끗한 사본에서. 배포 전 기계 관문(링크·바이너리·설정·의존성 변경 차단).
  • 콜드 감사: 구현 이력을 모르는 별도 모델이 diff 만 보고 반증 시도 — "아마 됐을 것" 은 FAIL.
  • 배포 금지시간: 증권 매매창·예매 오픈런·봇 평가시각·미국장 첫 사이클은 피하고 대기.
  • 배포 후 헬스체크(서비스 active · 새 코드 반영 · 로그 에러 없음) 실패 시 자동 롤백 + 알림.
  • AI 호출은 모델·턴 수·하루 호출 수·아이디어당 비용 상한 고정. 2회 실패면 멈추고 사람에게.
  • 입력은 소유자 전용 경로만. 이 공개 페이지엔 입력창이 없습니다.
